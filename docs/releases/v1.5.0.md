## Finger tracking

Fusion now offers **Finger tracking** for Quest Pro controllers: thumb-rest X rotates the thumb's
movement plane, Y bends the thumb, and trigger proximity/slide animate the index finger alongside
normal trigger input. Enable it in Settings while using Fusion. It is **off by default** on new
installations and updates without a saved preference. You can toggle it without restarting SteamVR;
turning it off or losing fresh sensor data restores the native animation.

- Fusion is the default driver mode for new installations. Existing driver choices are preserved.
- Finger tracking labels, tooltips and per-hand statuses are translated into all 12 interface languages.
- Native skeleton interception handles cached updates and compatible IVRDriverInput_005 interfaces,
  preventing alternating hand poses. Runtime publication avoids the lock inversion found in testing.
- Verified on Virtual Desktop with VRChat, including live toggling and reconnect recovery. SteamVR's
  OpenXR hand-joint API also returned valid data for both hands. Other transports are not yet verified.

## Required module update

**qptp-module v3.6 or newer is required** (versionCode 12, QPR4). Update the Quest module before using
this release. Older modules show the required-update screen. The app now negotiates QPR4 explicitly
and uses its contact flags instead of inferring touch from pad coordinates.

Download the Windows installer below, close SteamVR and QPTP, then run it to update.
